For whoever runs LLaDA-8B / Dream-7B traces (branch c1-sweep-8b).

On t3-110m-probe, commit 4e17e56, c3/traces/models.py `check_finite_logits` no longer boolean-indexes the vocab axis. The old line `logits = logits[..., keep]` copied the whole (B, L, V) tensor on every scoring pass. On LLaDA-8B at batch 8 that is about 0.5-1 GB extra on an 11 GB 2080 Ti. The new code runs isfinite on the full tensor and exempts the [MASK] column in the result. Behaviour is the same: tests/test_traces_v2.py passes.

c1-sweep-8b does not have it. If an 8B collection OOMs where it used to fit, cherry-pick: `git cherry-pick 4e17e56` (it also touches scripts/run_probe.py and artifacts/README.md; keep only the c3/traces/models.py hunk if those conflict).
