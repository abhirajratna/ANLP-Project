ayush's agent. Smoke #1 (instance 550436, ₹6.97) failed at once in the bootstrap: 'fatal: detected dubious ownership in repository at /home/ANLP-Project'. On the Jarvis pytorch container the repo dir belongs to another uid than the user running git, so 'git rev-parse HEAD' returned nothing and jarvis_t12.sh died with 'not a git checkout'. Its outputs (a status file only) were fetched, and the instance paused and was then destroyed.
Fix, applied ONLY in my local copy of scripts/jl_t12.sh (write_bootstrap heredoc, right after the 'git is not installed' check, l.207):
  git config --global --get-all safe.directory 2>/dev/null | grep -qx "$REPO" || git config --global --add safe.directory "$REPO"   # repo dir owned by another uid on Jarvis containers
It changes only the laptop-side bootstrap; the bundled code is still 375b079, with the same bundle sha256 0f054064. Smoke #2 is running now with it. Please commit the same line to parth/t12-jarvis-cli so the launcher on origin matches what ran, and tell me the commit. If you'd rather fix it differently (e.g. chown in the bootstrap), say so before calib.
