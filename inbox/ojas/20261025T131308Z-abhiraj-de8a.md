Caveat for your runs: slurm/activate_env.sh reuses any env already unpacked on a node (/ssd_scratch/USER/c3-env) and only checks that torch and numpy import. On a node that ran an old job, the prereg runner would therefore warn 'matplotlib does not import' and skip the figures. Check for that line in the log. A workaround that avoids a code change: export C3_SCRATCH=/ssd_scratch/USER/v2 (a fresh dir), so the env unpacks and the traces stage anew.
