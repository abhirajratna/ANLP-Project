\section*{Limitations}

\paragraph{Scope.}
We audit two 8B-scale families and one 110M MDLM of our own, on 256-token FineWeb-Edu
documents, GSM8K and MBPP. Base models read only web text and Instruct models only the tasks,
so model type and text type are confounded. The 8B models run in fp16, as our GPUs lack the
planned bfloat16; the precision control compares 4-bit with fp16 on
\VivaLladaBaseFourBitDocs{} documents, so the step to bfloat16 is not measured.

\paragraph{What is measured.}
C1 is teacher-forced: decoder states are those of a top-$k$ decoder that is always right,
not the states that follow a free-running decoder's own mistakes. A token is correct only if
it equals the reference, so a valid rewording counts as an error. E3 covers confidence top-$k$ trajectories only. C2's exact terms hold for one synthetic
distribution and one 110M fine-tune; on real text we have proxies (\S\ref{sec:c2-text}).

\paragraph{Estimands.}
The field term is only as context-aware as $\hat\pi(\ell,s)$, which sees a state through four
features; on simulated traces its estimator read high (\S\ref{sec:validation}), and E2
intervals are conditional on the fit-half calibrators. $\beta_z$ is a diagnostic, not an
endpoint: in simulation, fixed effects did not fully remove the field term, and shared errors
gave $\beta_z$ the opposite sign. Repeats were bitwise identical on one GPU type, and Instruct
models reuse their Base family's floor, so the zero floor says nothing about other hardware.

\paragraph{Contamination.}
The screen flags only verbatim recall ($\ge\VivaContamThreshold$ of 50 tokens); lighter
exposure to undisclosed 8B training data goes undetected. The time-split set is unseen by date
but is Wikipedia, so its contrast with FineWeb-Edu mixes exposure with domain; only the 110M
model, which saw neither set, isolates the domain part. Claims about levels therefore rest on
the 110M arm, as proposed, and the 8B arms carry claims about trends in field size; 110M
levels need not transfer to 8B models.

\paragraph{Pre-registration.}
Of the departures from the plan listed with the pre-registration (\S\ref{sec:prereg}),
three matter: the contamination threshold, the plan's value, was coded after the screen counts
were seen; the primary temperature control was switched after a fit-half development run;
and an exploratory notebook computed report-half statistics on both 110M arms before the tag.
Eq.~2/3 intervals use 1,000 resamples (knot panels 200, read as descriptive).

\paragraph{C3.}
The C3a calibrator is fitted on teacher-forced states and applied to free-running generation,
whose states it has not seen. It keeps the model's ranking by $\ell$, so it changes how many
tokens are committed, not which. The comparison uses one model, greedy decoding with one seed,
256-token outputs and two tasks.
